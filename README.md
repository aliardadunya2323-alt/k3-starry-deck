# K3 Starry Deck · 星空甲板

独立的 Three.js 互动场景：星空帆船、旅人与白猫、魔法和形态切换。

## 在线体验

[打开星空甲板](https://lucifer-d3g5l3wro6eec3ca4-1506797949.tcloudbaseapp.com/starry-deck/)

当前使用腾讯云测试域名，首次访问可能显示平台提示，点击“确定访问”进入。体验需要支持 WebGL 的浏览器。
在线演示现使用体验码解锁，请向作者索取。开源版本仍可直接在本地运行。
## 运行

安装 Node.js，然后执行 `npm start`，打开 http://127.0.0.1:7419/ 。已附构建产物，体验无需安装依赖。

## 开发

`npm install` 安装构建依赖；`npm test` 检查跳跃落地和边界；`npm run build` 重建网页。

## 操作

WASD 移动，Shift 奔跑，空格跳跃；鼠标拖动环顾，滚轮缩放。F 挥杖，1 冲刺，2 魔法阵，3 玫瑰，4 大阵（再次点击收回），5 切换形态，H 查看说明。

## 部署

将 `site/` 内容部署到静态网站根目录或独立子目录。无需后端、数据库或密钥。### 可选的加密体验入口`node tools/protect.mjs` 从标准输入读取体验码，生成未跟踪的 `.protected/` 发布目录。不要把真实体验码写进源文件、命令历史或 README。部署 `.protected/` 到原展示目录时，必须同时覆盖 `index.html` 和旧的 `app.js`。先上传其他文件，最后更新入口，可减少版本切换期间的加载失败。入口通过 PBKDF2-SHA256（600,000 次迭代）派生 AES-256-GCM 密钥；HTML 与场景程序在浏览器成功解密后才启动。体验码不写入发布文件、不保存在浏览器存储中，刷新后重新输入。可通过 `PORT=7421` 对应的环境变量和 `node tools/serve.mjs --protected` 在本机预览。这属于静态加密分享，不是账户登录或服务器访问控制：短体验码容易被离线猜测，模型与图片仍公开，开源程序以及先前下载的版本也仍可独立运行。需保护私人内容或严格限制访问时，应使用高强度口令或服务端认证。
